# 功能指南

首次使用请先查看[快速开始](getting-started.md)，完成安装和第一次下载。之后按要完成的任务选择对应指南。

## 下载视频与任务管理

选择当前、全部或指定分 P，设置画质上限，在下载中心管理进度。暂停队列会让当前任务完成；暂停单个任务会停止该任务并保留已提交缓存。

[视频、画质与任务](downloads.md)

## 下载缓存与大型任务

音视频在浏览器私有磁盘空间中下载和封装，不设固定输入大小上限，容量按剩余配额检查，输入和输出都占用空间。续传取决于缓存有效性和服务器支持；在下载中心的「下载缓存」查看用量和清理缓存。

[缓存与大型下载](../advanced/cache-storage.md)

## 批量来源

预览链接列表、收藏夹、合集、系列或 UP 主投稿，再导入勾选项。在线来源逐页读取，最近一次批量会话会在本地保存，重新打开后手动继续。

[批量下载](batch-downloads.md)

## 素材导出

保存 MP4 视频、M4A 音频、封面原图、SRT 字幕或弹幕 XML。素材组合可一次加入多种输出，分别保留每项结果。

[音频与配套素材](assets.md)

## 文件设置与记录

为新任务设置文件名模板与子目录，搜索和导出记录、跳过已成功的内容，或按之前的设置重新下载。

[文件与下载记录](files-and-history.md)

## 高级选项：本地助手

普通浏览器下载无需安装 Python 或 FFmpeg。如需浏览器配额之外的存储或本机 FFmpeg，可在「下载缓存」展开高级选项查看安装说明，并在音视频任务的「查看详情」→「高级选项：本地助手」中导出或交接任务。

[命令行助手](../advanced/native-helper.md) · [原生助手集成](../advanced/native-bridge.md)

查看[故障排查](../help/troubleshooting.md)、[权限说明](../help/permissions.md)与[隐私政策](../help/privacy-policy.md)。
