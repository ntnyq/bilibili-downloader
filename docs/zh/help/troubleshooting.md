# 故障排查

按现象查找处理方式。尽量重试原任务，以便校验并复用保留的缓存。

## 没有出现下载卡片

1. 确认扩展已启用，当前页面是 `https://www.bilibili.com/video/...` 下的普通视频。
2. 安装、更新或重新加载扩展后，刷新视频页面。
3. 在该视频页尝试使用工具栏弹窗。
4. 如果是 B 站页面结构变化，请反馈视频地址和浏览器版本，不要附带账号数据。

## 没有所需画质

扩展只能使用当前 B 站会话实际返回的流。先在 B 站登录，确认账号可以播放所需画质。「最高 720P」在没有符合条件的流时不会改用 1080P。更改默认画质只影响新入队任务，重试沿用原设置。

## 关闭标签页后下载中断

重新打开下载中心，重试原任务。下载期间保持下载中心打开，本地助手任务也一样。已提交缓存可能保留，但续传要求资源一致、强 ETag 和有效 Range 响应；资源改变或不支持续传时会安全重下对应资源。

## 暂停队列后仍在下载

「暂停队列」只阻止下一个任务开始。要停止单个任务的解析、传输或合并，使用该任务旁的「暂停」。最终保存阶段无法暂停，详见[任务控制](../guide/downloads.md)。

## 磁盘空间或浏览器配额不足

先暂停队列，等待正在下载或合并的任务停止，再清理缓存。释放磁盘空间后重试。封装需要同时保存输入和输出，最终下载文件也需要空间；浏览器配额估算不等于系统剩余磁盘空间。大型任务可考虑[本地助手](../advanced/native-helper.md)，但浏览器与助手缓存相互独立。

## 保存的文件无法在旧编辑器中打开

浏览器封装可能输出分片 MP4 / M4A，部分旧播放器和编辑器兼容性较低。可以尝试支持分片 MP4 的播放器，或通过 [FFmpeg 助手](../advanced/native-helper.md)使用本机 FFmpeg 生成输出。

## 缺少字幕、弹幕或音频

来源可能没有提供对应素材。部分字幕需要登录；音频导出需要独立 AAC 音轨。弹幕是当前接口快照，不是完整历史。素材组合中缺失的素材会保留为失败项，可独立重试。详见[素材边界](../guide/assets.md)。

## 批量导入停止或跳过了视频

- 私密收藏夹需要先登录并具有访问权限；短链接需在浏览器打开，再复制完整链接。
- 需要手动读取下一页，每份预览最多 500 条。
- 活跃重复任务始终跳过；默认也跳过长期成功历史中的相同内容，且不区分画质。如需再次下载，可关闭成功跳过选项。
- 登录、风控、网络或容量错误会停止导入，已入队内容保留。处理原因后手动继续。
- 另一个下载中心修改会话时，先载入最新版本再继续。

来源格式和队列限制见[批量下载](../guide/batch-downloads.md)。

## 本地助手连接失败

确认已安装 Python 3.10+ 和 FFmpeg，使用当前扩展 ID 为对应浏览器注册宿主，并允许可选的原生通信权限。仅构建扩展不会注册宿主。安装、恢复步骤和平台验证边界见[原生助手集成](../advanced/native-bridge.md)。

## 反馈问题

[创建 Issue](https://github.com/ntnyq/bilibili-downloader/issues) 时提供浏览器与扩展版本、复现步骤、界面错误，以及问题发生在浏览器下载还是助手下载。适合公开时可提供视频链接，请删除 Cookie、带签名的 CDN 地址、`.bili.json` 内容和私人下载记录。

当前测试范围见[验证记录](../development/verification.md)。直播、番剧、互动视频和受保护内容仍不支持。
