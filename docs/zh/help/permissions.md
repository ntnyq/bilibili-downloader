# 权限与本地数据

扩展申请识别视频、请求所选内容和保存文件所需的权限。本页说明清单中的权限用途，完整数据政策见[隐私政策](privacy-policy.md)。

## 必需的浏览器权限

| 权限                                  | 用途                                         |
| ------------------------------------- | -------------------------------------------- |
| `storage`                             | 在本地保存设置、队列状态、批量会话和下载记录 |
| `activeTab`                           | 从工具栏弹窗识别当前视频                     |
| `tabs`                                | 查找、打开扩展和视频标签页，并进行通信       |
| `downloads`                           | 通过浏览器下载管理器保存生成的文件           |
| `declarativeNetRequestWithHostAccess` | 为扩展发起的相关请求设置 B 站 Referer        |

## 站点访问范围

| 站点范围                                                                   | 用途                                   |
| -------------------------------------------------------------------------- | -------------------------------------- |
| `www.bilibili.com`                                                         | 显示视频页卡片、读取当前视频信息       |
| `api.bilibili.com`                                                         | 获取视频元数据、播放流、字幕和批量列表 |
| `comment.bilibili.com`                                                     | 获取弹幕                               |
| `bilivideo.com`、`bilivideo.cn`、`bilivideo.net`、`akamaized.net` 的子域名 | 获取媒体流                             |
| `hdslb.com` 的子域名                                                       | 获取封面等图片                         |

API 请求允许浏览器附带已有的 B 站会话。扩展不索要密码，不通过 Cookie API 读取原始 Cookie，也不向助手导出 Cookie。媒体下载不附带登录凭据。

## 可选权限

| 权限              | 申请时机           | 用途                                  |
| ----------------- | ------------------ | ------------------------------------- |
| `notifications`   | 开启完成通知时     | 保存成功后显示系统通知                |
| `nativeMessaging` | 选择交给本地助手时 | 与另行安装的 Python / FFmpeg 宿主通信 |

普通浏览器下载不需要启用这两个功能。宿主仍需用户另行安装，详见[原生助手集成](../advanced/native-bridge.md)。

## 数据存储与删除

| 数据                         | 位置与删除方式                                           |
| ---------------------------- | -------------------------------------------------------- |
| 设置、队列、最近一次批量会话 | 扩展本地存储，可在界面清除提供清除操作的记录，或卸载扩展 |
| 长期成功历史                 | 本地存储，最多 5000 条 / 3 MiB，在长期下载记录中删除     |
| 浏览器媒体缓存               | 扩展私有磁盘空间，没有任务正在下载或合并时可清理         |
| 已下载文件与导出文件         | 普通文件，通过文件管理器删除                             |
| 助手文件与缓存               | 独立安装目录和输出目录，需要另行删除                     |

清除历史不会删除已保存文件，清除队列会保留长期历史。卸载扩展不会卸载助手，也不会删除普通下载文件。

扩展不使用开发者运营的服务端、统计 SDK、广告 SDK 或跨设备同步。导出的 `.bili.json` 任务文件包含临时媒体地址，请保密保存。
