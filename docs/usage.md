# Feature guide

Start with [getting started](getting-started.md) for installation and your first download. Choose a guide below for the task you want to complete.

## Downloading and managing tasks

Choose current, all, or selected parts, set a quality cap, and manage progress in the download center. Queue pause lets the current task finish; individual pause stops that task and retains committed cache.

[Video, quality, and tasks](downloads.md)

## Cache and large downloads

Video and audio use browser-private disk storage. Resume depends on valid cached data and server support; input and output both count toward available quota. The optional Python / FFmpeg helper runs outside browser quota limits.

[Cache and large downloads](cache-storage.md) · [Local helper](native-helper.md) · [Native integration](native-bridge.md)

## Batch sources

Preview links, favorites, collections, series, or creator uploads, then import selected items. Online sources load one page at a time. The latest batch session is saved locally and waits for you to continue.

[Batch downloads](batch-downloads.md)

## Asset exports

Save MP4 video, M4A audio, original covers, SRT subtitles, or danmaku XML. Asset bundles queue several outputs together while preserving each member's result.

[Audio and companion assets](assets.md)

## File settings and history

Set filename templates and subdirectories for new tasks. Search and export records, skip past successes, or requeue a previous download with its saved settings.

[Files and download history](files-and-history.md)
